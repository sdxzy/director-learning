阶段二

故事结构

先能用一句话说清，再谈三幕和英雄之旅。结构是脚手架，不是监狱。

一句话梗概（Logline）

是什么

公式：一个（有特点的）主人公 + 想要什么 + 遇到什么阻碍 + 赌注是什么。

为什么重要

写不出来 logline，通常是故事核心还糊。AI 短片选题也一样：一句话说不清，就别开工。

怎么用

例子

一位患癌的高中化学老师，为了给家人留下钱，开始制毒，却一步步变成自己最恐惧的人。（《绝命毒师》）

每天写 3 条，坚持两周，你会明显感到「什么算一个故事」。

练一练

今天写下 3 条 logline，挑一条最想拍的留下来。

三幕剧结构

是什么

  • 第一幕（约前 25%）建置：日常世界；激励事件打破平衡；主人公决定进入新局面。
  • 第二幕（约中间 50%）对抗：追目标，阻碍升级；中点大转折；结尾掉进「最低谷」。
  • 第三幕（约最后 25%）解决：最终选择 → 高潮 → 结局。

为什么重要

观众需要「提问 → 越来越难 → 回答」。没结构的故事像散步，有结构的故事像登山。

怎么用

一句话记住：提出问题 → 把问题搞得越来越难 → 回答问题。

《救猫咪》的「节拍表」是把三幕拆成可填空的检查点，零基础特别好用。

练一练

用救猫咪节拍表拆一部你熟的电影，只标 8–15 个关键节拍即可。

英雄之旅（简版）

源自约瑟夫·坎贝尔，沃格勒整理为约 12 阶段：平凡世界 → 召唤 → 拒绝 → 导师 → 门槛 → 考验盟友敌人 → 深穴 → 磨难 → 奖赏 → 返回 → 复活 → 携药回归。

把它当检查清单：故事有没有成长感？而不是必须逐步打卡的公式。
