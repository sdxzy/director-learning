阶段四

角色一致性

观众最容易出戏的一点：下一镜主角的脸变了。剧集向创作，这是核心难题。

是什么

  1. 角色设定图 Character sheet：正面清晰、光均匀、表情中性的定妆照 + 正/侧/背 + 全身。
  2. 参考功能：Runway @参考、即梦/可灵多图参考、Veo 3.1 参考图、Vidu 参考生视频。
  3. 固定描述词：发型、服装、年龄、特征写成一段，每次原样复制。
  4. 服装道具锁定：一场戏内少改变量。
  5. 场景参考图：主场景也做参考，跨机位复用。
  6. 先图后视频：关键帧先一致，再转视频，比直接文生视频稳。
  7. 后期修补：局部重绘、视频编辑工具修最刺眼的不一致。

为什么重要

没有一致性，就没有「同一部剧」。这比单镜炫更重要。

怎么用

开工模板：角色设定文件夹 + 固定外貌段落 + 场景参考 + 分镜表里标注「必须吃参考」的镜头。

练一练

为主角做正/侧/背 + 3 种表情，并在 5 个不同场景测试是否像同一个人。

一句话记住：先定妆与参考图，再生成；先图后视频更稳。
